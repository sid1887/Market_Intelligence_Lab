# Market Intelligence Lab (Indian Equities)

A modular, local-first quantitative research and market intelligence platform for Indian equities (NSE & BSE).

## Architecture Principles
1. **Local Data Sovereignty**: All market history, corporate filings, derived indicators, and audit trails reside in local SQLite storage (`data/market_lab.db`) and local files.
2. **Deterministic Mathematical Foundations**: All return calculations, annualized volatilities, drawdowns, and range positions are computed using verified deterministic mathematical algorithms in Python (never generated by LLM approximation).
3. **Verified Official Data Sources**: Ingestion utilizes the official National Stock Exchange of India (NSE) Model Context Protocol (MCP) Streamable HTTP endpoints (`https://mcp.nseindia.in`), with support for standardized CM-UDiFF archival files.
4. **Data Integrity & Schema Enforceability**: Missing or unpopulated delivery quantities and turnover fields are explicitly stored as `NULL` (never falsely coerced to `0`). Every record is validated against exchange logical invariants ($H \ge L$, $O/C \in [L, H]$, $V \ge 0$).
5. **Session Continuity & Calendar Validation**: Trading date sequences are validated against the official NSE holiday calendar to distinguish exchange closures from unexpected observation gaps.
6. **Corporate Action Adjustment**: Historical price discontinuities on ex-dates (dividends, splits, bonuses) are captured and adjusted to prevent false attribution to market losses.
